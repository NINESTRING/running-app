# 러닝 중 지표 패널 상단 이동·확대 설계

2026-08-18

## 목표

달리는 도중 화면을 흘긋 봤을 때 거리·시간·페이스·케이던스와 목표 편차가 바로
읽히게 한다. 지금은 지표가 화면 맨 아래 카드에 `text-2xl`로 몰려 있어 뛰면서
읽기 어렵다. 지표를 화면 상단으로 올리고 글자를 크게 키운다.

## 요구사항

- 러닝·일시정지·저장 중에는 지표가 **화면 상단**에 표시된다.
- 조작 버튼(일시정지/재개/종료/저장 중…)은 **하단에 그대로** 둔다. 달리면서
  한 손 엄지로 눌러야 하므로 상단으로 올리지 않는다.
- 지표 4개는 한 줄이 아니라 **2×2 격자**로 배치하고 값을 대폭 키운다.
- 시작 전(idle) 화면은 **지금과 동일**하다. 하단 카드 하나에 목표 요약 +
  지표 + 시작 버튼.
- 계산 로직(`geo`·`goal`·`splits`·`cadence`)은 건드리지 않는다. 순수 표현 변경.

## 레이아웃

`status !== 'idle'` (running · paused · saving) 일 때 카드가 둘로 나뉜다.

```
[시작 전 idle]              [러닝 중]
┌──────────────┐           ┌──────────────┐
│              │           │  0.12  00:36 │ ← 상단 카드 top-4
│              │           │  4'59"   --  │   지표 2×2
│     지도      │           │  구간 1·4'44" │   구간 줄
│              │           │  ▼13m 뒤쳐짐  │   목표 편차
│              │           ├──────────────┤
│   [내위치]    │           │              │
│ ┌──────────┐ │           │     지도      │
│ │목표  [목표]│ │           │              │
│ │ 0.00 지표 │ │           │ ┌──────────┐ │
│ │  [시작]   │ │           │ │[일시정지][종료]│ ← 하단 카드 bottom-6
│ └──────────┘ │           │ └──────────┘ │
├──────────────┤           ├──────────────┤
│ 홈 기록 통계 설정│           │ 홈 기록 통계 설정│
└──────────────┘           └──────────────┘
```

`saving`도 상단에 남긴다 — 종료 다이얼로그에서 "저장"을 누른 직후 지표가
아래로 튀는 것을 막는다.

상단 인셋은 `app/(tabs)/_layout.tsx`의 `sceneStyle: { paddingTop: insets.top }`이
이미 처리하므로 `top-4`만으로 노치·다이내믹 아일랜드 아래에 들어간다.
별도 safe-area 작업 없음.

## 글자 크기

| 요소 | 현재 | 상단(러닝 중) | idle |
| --- | --- | --- | --- |
| 지표 값 | `text-2xl` | `text-4xl` | `text-2xl` 유지 |
| 지표 라벨 | `text-xs` | `text-sm` | `text-xs` 유지 |
| 구간 줄 | `text-sm` | `text-lg` | — |
| 목표 편차 | `text-sm` | `text-xl font-semibold` | — |

거리 목표가 있을 때(`0.12 / 5.00`)만 예외다. 375pt 화면에서 격자 한 칸은
약 155pt인데 11글자를 36pt로 넣으면 넘친다. 이 경우 값은 `text-3xl`,
목표 부분(`/5.00`)은 중첩 `Text`로 `text-xl text-muted-foreground`.
현재 값이 크게, 목표가 작게 붙는다.

목표 거리 달성 시 초록색(`distanceReached`) 처리는 그대로 유지한다.

## 컴포넌트 구조

`app/(tabs)/index.tsx` 안에서 처리한다.

- `MetricsGrid({ size })` — 지표 배치. `size='large'`면 2×2 격자에 `text-4xl`,
  `size='compact'`면 지금처럼 한 줄에 `text-2xl`. 값·라벨 클래스만 달라지므로
  기존 `Metric`을 그대로 재사용하고 클래스를 주입한다.
- `RunStatsCard` — 상단 카드. `MetricsGrid size="large"` + 구간 줄 + 목표 편차 줄.
- 하단 카드는 idle이면 목표 요약 + `MetricsGrid size="compact"` + 시작 버튼,
  아니면 버튼만. 버튼만 남을 때는 `Card`의 `py-6`를 `py-0`으로 눌러 두꺼운
  세로 여백을 없애고, 버튼에 `flex-1`을 줘 글자 수와 무관하게 카드 폭을
  똑같이 나눠 갖게 한다(`일시정지`가 `종료`보다 넓어 보이던 문제).
- `permissionDenied` 안내는 하단 카드에 남긴다 — 내 위치 버튼·시작 실패와
  붙어 있는 편이 자연스럽다.

`liveSplits`·`goalDelta`는 이미 running/paused에서만 non-null이므로 상단
카드로 옮겨도 조건이 그대로 맞는다.

## 검증

순수 표현 변경이라 새 테스트는 추가하지 않는다. 이 프로젝트의 테스트는
`src/lib`·`src/stores`·`src/services` 단위 테스트만 있고 컴포넌트 테스트는 없다.

- `npx tsc --noEmit`
- `npm run lint`
- `npm test` (기존 테스트 회귀 없음 확인)
- 실기기 수동 확인: 375pt 폭에서 `0.12 /5.00`이 줄바꿈 없이 들어가는지,
  상단 카드가 상태바를 침범하지 않는지.
